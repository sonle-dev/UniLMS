# 📦 EduPortal - Legacy Static Prototype (Lưu trữ lịch sử)

Đây là bản giao diện mẫu thử nghiệm ban đầu (Prototype) được xây dựng bằng **HTML5 / CSS / Vanilla JavaScript** thuần trong giai đoạn thiết kế ý tưởng.

## ⚠️ Lưu ý quan trọng
* Bản này **không còn được sử dụng trong môi trường chính thức**.
* Hệ thống chính thức của UniLMS hiện tại đã được đồng bộ chuẩn hóa 100% sang kiến trúc Monorepo Enterprise:
  * **Frontend chính**: [frontend/](../../frontend/) (React 18 + Vite + Tailwind CSS)
  * **Backend chính**: [backend/](../../backend/) (Spring Boot 3.2.3 + PostgreSQL 15+)
* Toàn bộ mã nguồn cũ được lưu trữ tại đây chỉ nhằm mục đích tham khảo lịch sử phát triển giao diện.
